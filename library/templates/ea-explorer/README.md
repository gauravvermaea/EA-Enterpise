# EA Explorer's own template library

A starter file for each of the 171 deliverables and artifacts of the project library, in the folder of each
(`09_ADM_Phase_Workspaces/<phase>/Deliverables or Artifacts/<nnn_name>/`). 108 are worked samples (the fictional
Meridian Assurance Group's), with the organisation's name replaced by **[Organisation]** in their text; pictures inside
them are kept as they were. The other 63 are plain starter files: a Word document for deliverables, an Excel workbook for
catalogues, matrices and registers, a PowerPoint deck for diagrams. Nothing here comes from The Open Group's templates.

Built by `tools/build_ea_explorer_templates.py` (do not edit by hand; `manifest.json` lists each file and its item).
Mounted read-only into the API at `/data/ea-explorer-templates`. To make your own library from it, see
[../own/README.md](../own/README.md).
