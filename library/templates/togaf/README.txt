
README

When developing architecture documentation, it is recommended to
create "((just enough for the purpose))". This approach encourages
architects to focus documentation efforts where they add value
rather than creating comprehensive documentation for its own sake.

Consider carefully the limitations of restricting architecture
descriptions to only areas with identified gaps. If portions of the
Enterprise Architecture Landscape will remain unchanged and are not
needed for traceability purposes, there may be little justification
for architects to spend time documenting these elements.
