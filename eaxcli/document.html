Starting and stopping at a glance

CommandWhat it doesYour data
up (or run)Starts EA Explorer: the core first, the rest in the background (--wait-all waits for everything).Kept from last time
stop (or down)Stops EA Explorer: stops and removes the containers. Use it before shutting the computer down or to free memory.Kept: databases, documents, settings, backups
restartstop, then up (each with its own log). For when something is stuck.Kept
statusEvery container's state and health, and the disks. Changes nothing.Kept
cleanup --allStops EA Explorer and deletes the work folder and the databases (asks you to type yes).Deleted (the trusted certificate is kept)
clean-restartStops, deletes everything and starts fresh with the sample data. Does not ask.Deleted

To stop without losing anything, always use stop.

The console

console is the place to start when something is wrong, for anyone: a numbered menu that says what to do in plain words. It shows the status, starts, restarts and stops EA Explorer, shows problems and logs, backs up and restores (guided), resets passwords, manages users and roles, settings and switches, and saves a diagnostics file. Anything that changes or replaces data asks you to type YES; on this machine nobody signs in. Its c item gives a prompt for every eax command. With --server it works on another installation through its API.
