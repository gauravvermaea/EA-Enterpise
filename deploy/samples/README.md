# Sample files (phase 10.1)

- `cmdb-applications.csv`: an export from another system (semicolons, its own headers). Upload it on the Import and export tab of
  Protea Insurance (demo estate): EA Explorer asks you to map its columns (or use the saved mapping *CMDB applications*),
  matches the three applications it already has by name, and shows the two new ones.

Sheets made by EA Explorer itself are built on the fly from any model: Import and export tab > choose the types > Build and download.
