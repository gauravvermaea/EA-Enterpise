# EA Explorer 1.1.0 (in progress on main)

Release 2's first stories. Not released yet: this file grows as each story is built and accepted.

## R2.0: a usable UI with a simple menu (built 11 Nov 2026, to be accepted)

- **A menu bar**: Architecture Work, Model Admin, Project Admin, Repository & Content Framework (the Architecture
  Repository and the Content framework together) and System Admin, each a drop-down with sub-menus; on the right your own menu (your name:
  your work, your profile, Sign out) and **?** (help and documentation); at the top left the site picker, **● Local**
  (Farm Admin). Last model and Last project side by side. Every screen, tab and wizard of 1.0 is in it (a test checks
  nothing is left out). What you may not use is not shown (D586, D588, D591).
- **Wizards**: click Wizards for the wizards page, or pick one wizard from its sub-menu (D587, D591). On a project page
  the Repository and Content framework tabs sit together.
- **Find: press /** (or Ctrl+K, or the box at the top) for any function, with where it is in the menu, or content:
  models, projects and entities as you type, and Search everything (D590).
- **Menu | Classic**, a toggle at the top right: Classic keeps the menus of 1.0 for now. The left-menu tab style and the
  first sign-in question are gone (D589). This also answers R2.6 (changing the layout did nothing on most pages).
- **Farm Admin** (Super Admins), from the site picker: Sites and Connect to a site, saying what R2.1 and R2.2 bring.

See [docs/r2-0-menu.md](../docs/r2-0-menu.md) for where everything is.

## R2.0.1: testing that works, simply (in progress)

- **Two choices**: the Smoke test or the Full test, on System Admin › Tools › Self-test or with `eax test` /
  `eax test full`. Each run starts its own test container, tests, reports and removes it (D592).
- **Test data cleaned up**: each run removes what earlier runs left first; `eax test clean` and **Delete all test data**
  remove it at any time (D593).
- **Fixed**: the self-test and updates stopping with "the installation folder is not known" (the folder is now found
  from any of the installation's files the helper has, R2.8); the quality PDF and Excel of a model never measured; a
  malformed stakeholder id giving a server error; the change log's screen waiting behind its own set-up.
- `eax testbench` is no longer a command (CI keeps the test bench).
- **Model library and Project library for everyone**: both in Architecture Work (and Repository & Content Framework ›
  Libraries); the Project library has its own page, and library projects can be read by anyone with a role (D594).
- **Fixed**: the Documentation page's documents and the library's EA Explorer documentation folder not found on an
  installation (the documents were looked for in the document store's folder); reports-init showing "unhealthy" after it
  finished (R2.20). A test run does not depend on the sample data or the industry packs (D595).
- **Fixed in the self-test** (D596): the API writes run again (they were all skipped); the browser journeys wait for pop-ups, fields and choices on a slower computer; the test data is found on Windows. A server error now says what kind it was and its request id. The front door no longer lets other sites frame it or tells its nginx version.
- **Start-up finishes in one start** (D597): the industry packs load file by file beside the sample data, with progress that moves; one file that fails no longer undoes the others; Reports no longer stays "Created".
- **Security** (D598): newer cryptography, pypdf, draw.io (32.6.10), Docker CLI and PostgreSQL images, and each image takes its distribution's fixes when built.
- **Fixed**: making a gap analysis or a common analysis ("column domain does not exist"); a slow page or a project's download ending in a bare server error after 30 seconds.
- **Start-up** (D600): the API no longer runs out of memory loading the industry packs (one file at a time; 2 GB on a laptop); Reports is up within minutes and loads its dashboards afterwards; a loader that stopped says so.
- **Containers**: CPU is shown as a share of the whole machine, with the cores in use, so the total no longer passes 100% (D601).
- **Views**: Standard views is the first sub-tab and opens by default; Custom views next. A model's picture opened in draw.io shows the objects on it and their properties, relationships and allowed relationships, read only (D602, R2.7).
- **Self-test results by importance** (D604): every check critical or not, a ring chart and a functional health (Healthy, Degraded, Not healthy) in the report, on the Self-test page and at the end of `eax test`, with every failure listed.
- The Reports tab "Power BI and Excel" is now **OData**; the Classic button is gone (D603).
- **Run the failed ones again** (D605): Self-test › History or a run's results, or `eax test failed [run] [--warnings]`: only the checks that failed, in fresh test data; the results show each check then and now, and the earlier run is marked followed up when all pass. The Command centre now also takes `test full` and `test failed`.
- **Fixed**: on Windows, a self-test or command started from the web (Self-test, Run the failed ones again, the Command centre) could not start ("the working directory ... is invalid"). A backup that cannot read a file now says which set and which file.
- **The Classic screens are gone** (D606): the menu bar is the only menu; every page Classic reached is in it.
- **Fixed on Windows**: Run the failed ones again, and anything the Self-test page or the Command centre starts, now runs (the installation folder mounted the way Docker Desktop needs). A command that starts or stops containers is not run from the web on Windows: the page gives the PowerShell line instead.
- **Architecture principles as cards** (D607): grouped by area, with statement, rationale and implications; Repository › Architecture principles for everyone, and each project's Principles tab; edit on the card, add from the library, refine an enforced one.
- **The self-test checks backups** (D608): the full test ends with an infrastructure and an application backup, each restored into a scratch copy and counted, then removed; also `eax test backup`. Until they pass, the Backups page shows the commands to run instead of its buttons.
- **A test in progress keeps normal users out** (D609): who signs in meanwhile sees "Environment test in progress" and gets in when it ends; changes wait; admins see only the Self-test page.
- **Checks left** while a self-test runs, on the page and the command line, and **deleting test results** (reports, logs, videos, screenshots) from History or `eax test delete`, and by themselves after 30 days (D610).
- **Every database has its own setting** (D611): empty = the shared PostgreSQL; set one to move that database to its own container or server. System Admin › Databases and `eax databases` show where each lives; backups follow each one.
