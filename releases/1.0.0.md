# EA Explorer 1.0.0: Release 1

The first release of EA Explorer: an open-source enterprise architecture repository (AGPL-3.0), installed and run on
your own laptop, server or cloud. Release 1 is 0.19.0 with the last fixes; the full detail of each part is in
[0.19.0](0.19.0.md) and in the Documentation menu.

## What it does

- **A repository with a metamodel you control**: ArchiMate 4 and TOGAF 10 built in, your own entity types, attributes
  (including links), relationship rules with multiplicity and relationship attributes; models, child models, tags,
  history and compare.
- **Drawn views in draw.io**, inside EA Explorer: two-way sync with the model, the ArchiMate notation, relationship
  tabs, name : type labels, undo; every picture of a model opens read only in our own draw.io (save it as a drawn view or
  download it), and draw.io's Export as menu has a .drawio file (D585).
- **Keeping it clean**: quality checks, duplicates found and merged, merging a child model into its parent, KPIs with
  trends, an OData feed and a report designer.
- **Projects on the TOGAF ADM**: purpose, scope, phases and ADM iteration types, deliverables, key questions,
  governance log, sign-off, scenarios, surveys and EA capability maturity.
- **Industry reference models and packs**: ten industries, with the books, workbooks and metamodel Excels to download.
- **Importing**: published Excel and CSV formats, deliveries reviewed before loading, and a model from a metamodel
  workbook.
- **AI through MCP**: about 120 tools for reading, analysing and changing models, each change previewed and confirmed,
  with an AI activity log.
- **Running it**: `eax deploy` (laptop, server, AWS, Azure, DigitalOcean), updates and rollback from the repository,
  backups and restore, machine access, operations insight, the Command centre and web console, schedules, a banner,
  settings that survive resets, on-screen help for every screen and the Documentation menu.

## Known limits, for Release 2

- **The self-test** (System admin › Self-test, `eax test`) and the outside test bench are on hold: they become one
  separate test container, the first thing in Release 2.
- **Start-up**: on some installs the last sample-data steps and the industry-pack load into Documents do not finish;
  everything else works. Fixed in Release 2.
- See docs/build-phases.md (R2) for everything planned next.

## Before updating

A fresh install: `.\eax clean-restart` (Windows) or `./eax.sh clean-restart`. From 0.19.0: update through System admin ›
Updates or `eax update`; a full backup is taken first.
