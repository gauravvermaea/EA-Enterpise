# EA Explorer 0.19.0

The last set before version 1.0 (D421).

## What is new

- **Updates from the repository**: System admin > Updates and `eax update` move EA Explorer to a newer release, from the
  Prod, RC or Latest channel, with a full backup first, one release at a time, and Retry or Roll back if a step fails.
- **Releases**: CI on every change, versioned releases with these notes, and a supported-versions policy.
- **Command centre** (System admin): every eax command from the browser, with a guided form, a Console for typing them
  (and `eax console`'s menu) and the history of every run; the same on `eax deploy`'s page.
- Everything accepted up to 0.18.0: drawn views in draw.io, merge and dedupe, KPI trends, OData and the report designer,
  machine access, operations insight, surveys and maturity, import formats, industry models, MCP and scenario planning.

## Also in 0.19.0: banner, schedules, settings that survive resets

- **Banner** (System admin > Banner): one message under the top bar, information, notice or urgent, with optional times
  and audience. Nothing shows unless an admin sets one.
- **Schedules** (System admin > Command centre > Schedules, `eax schedule`): eax commands that run by themselves, e.g.
  a nightly backup, a weekly smoke test, or **Demo reset every night** (`clean-restart laptop` at 02:00 with a banner).
- **persist/**: schedules, the banner and safety backups live in a folder beside `work/` that no reset deletes, as
  small JSON files you can read and edit; it is in every infrastructure backup.
- **Reset-survival test**: `eax test --reset-survival` (or the Self-test page's opt-in) proves it with a real reset.

## Also in 0.19.0: relationship attributes and line labels
- Relationships carry the attributes the metamodel defines, per relationship type or per allowed relationship (D563, D564), edited as key : value in the relationship list, a drawn view's line Properties, Excel and MCP; required ones are checked by quality.
- Drawn view lines read `name (Type) [key:value …]`, and naming a line never hides its type; **Line labels** in the toolbar hides the values on busy diagrams (D565).
- Migration 0047 adds the table that limits an attribute to some allowed relationships.

## Before you update

- A full backup is taken first (every database, every file, the configuration and the code), and kept pinned.
- The first update to this version needs `eax clean-restart` once, so the operations helper can read the releases.
